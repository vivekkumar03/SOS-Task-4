# SOS Assignment Task 4 -Encryption Decryption

This directory contains the C sources for the password-based encryption/decryption program. It is a coursework example, not a production security product. For macOS/Linux prerequisites, handoff contents, and run instructions, see the [project README](../README.md).

For a beginner-friendly explanation of the cryptography and each source file, see [GUIDE.md](../GUIDE.md).

`make clean` removes the object file, both program binaries, and `text.ct`; back up ciphertext before running it.
